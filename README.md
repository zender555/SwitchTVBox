## 功能

- 海报片库、分类浏览、搜索与筛选，支持翻页和选集。
- 夸克、百度网盘扫码登录，浏览自己的网盘及分享内容。
- 「网盘」入口支持搜索公开分享，使用已登录账号保存选集并播放。
- 「免登1」「免登2」独立入口，无需网盘登录；支持分类、封面、选集及可用备用线路切换。
- 本地播放历史与续播、昼夜主题、网络诊断，支持中文界面和手柄操作。

第三方来源和分享链接可能失效；搜索有结果不代表链接、转存或播放一定可用。

## 安装与更新

1. 通过上述交流渠道获取安装包 `SwitchTVBox-v版本号.zip`。
2. 解压后将其中的 `switch` 文件夹复制到 SD 卡根目录。程序路径应为 `switch/SwitchTVBox/SwitchTVBox.nro`，请保持目录名和文件名的大小写。
3. 更新时替换 NRO 文件，保留本机已有的账号、配置及历史记录。
4. 通过支持完整内存模式的 Homebrew 启动方式打开 SwitchTVBox。
5. 使用网盘功能时扫码登录；「免登1」「免登2」无需网盘登录。

安装包不包含账号文件、账号模板或默认配置。目前提供 NRO，不提供 NSP 桌面安装器。
